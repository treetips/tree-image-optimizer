# 設定ファイル

変換画面の各種設定値は人によって異なるものです。

起動する度に毎回その設定を選択することが面倒なので、設定ファイル化し、次回起動時に設定値が復元されるようにしたいです。

アプリ起動時に、アプリ内の初期値を `$HOME/.config/tree-image-optimizer/settings.json` に保存します。

変換画面で設定値を変更すると、 `settings.json` が更新されます。

アプリを終了して再度開く際に `settings.json` を読み込み、変換画面に設定値を反映します。

設定値の反映時に以下の状況になる場合、アプリ内で定めている初期値で `settings.json` を更新し、変換画面にも反映します。

- 設定項目に値が無い場合
- 存在しない設定値
