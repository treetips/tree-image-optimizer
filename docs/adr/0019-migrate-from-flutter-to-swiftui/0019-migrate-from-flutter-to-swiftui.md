# FlutterからSwiftUIに移行する

現在クロスプラットフォームのためにFlutterを採用しています。
しかし、以下の理由で

Windowsの動作確認が困難なのと、Windowsのバイナリ配布状況を常に考慮するのが辛いです。

## 画面のUI

[画面仕様](../../design/feature/images) フォルダに各画面の画面スクリーンショットがあります。

## UIがSwiftUIベースにする

画面仕様書はAppleを意識しないUIになっています。

機能は完全に踏襲したいですが、UIは `AppleらしいUI` 、例えばFinderのサイドナビや `Liquid Glass` のような、AppleらしいUIに置き換えたいです。

## バージョン

全て2026/09時点での最新バージョンを使うこと。

## 移行計画

1. 【フェーズ1】このプロジェクトをSwiftUIに移行する。 `docs/design/migrate.md` に移行計画をまとめる。
2. 【フェーズ2】まずはUIだけを作成する。ただし、画面遷移だけは実装する。この時点で私がUIについて誤り等を指摘する。
3. 【フェーズ3】機能を実装する。ただし、先にテストクラスを作成してから各機能を実装していくこと。
