# Flutter 3.47へのアップグレードとmaterial_ui移行

## ステータス

- 承認済み (Accepted)

## 背景・課題

Flutter 3.47がリリースされた。主な変更点は以下。

- macOSの最低対応バージョンが `10.15 → 12` に引き上げ。
- デスクトップ(macOS/Windows/Linux)で Impeller がデフォルトレンダラーに。
- Material / Cupertino が独立パッケージ `material_ui` / `cupertino_ui` として提供開始(今年11月にコアSDK側の非推奨化が予定)。
- Swift Package Manager の利用が推奨に。

## 決定

- **fvm で Flutter を 3.47.1 にアップグレード**する。
  - `fvm install 3.47.1` を実行し、`.fvm/fvm_config.json` を `3.47.1` に更新。
- **macOS の最低対応バージョンを 12.0 に引き上げ**る(Flutter 3.47の必須 breaking change)。
  - `project.pbxproj` の `MACOSX_DEPLOYMENT_TARGET` と `Podfile` の `platform :osx` を更新。
- **Impeller**: デスクトップでデフォルトのため特別な設定は不要(自動適用)。
- **material_ui へ移行**する。
  - `flutter pub add material_ui` を追加し、`dart fix --apply --code=migrate_design_widgets` で
    `package:flutter/material.dart` のimportを `package:material_ui/material_ui.dart` に置き換え。
  - `MaterialUiCompatibilityBridge` は「依存パッケージの移行中のみ使う一時的ユーティリティ」であり、
    本プロジェクトの依存はMaterialウィジェットを使わず全importも移行済みのため、導入しない。
  - Cupertino・flutter_localizations は未使用のため対象外。
- **SwiftPM**: 非対応のプラグイン(`auto_updater_macos`, `flutter_desktop_notifications`)が
  動作しなくなるため、現時点では**CocoaPodsを維持**する。

## 代替案

- material_uiへの移行を保留する
  - 却下: 11月の非推奨化に先んじて移行し、今後の独立更新を受けられるようにするため。
- SwiftPMを有効化する
  - 却下: 依存プラグインがSwiftPM非対応で、ビルドが失敗するため。

## 結果

- Flutter 3.47.1で動作し、`flutter analyze` 0件・テスト32件成功・macOSビルド成功。
- 変更箇所: `.fvm/fvm_config.json`、`pubspec.yaml`、`macos/Runner.xcodeproj/project.pbxproj`、
  `macos/Podfile`、`lib/**` と `test/**` のimport。
