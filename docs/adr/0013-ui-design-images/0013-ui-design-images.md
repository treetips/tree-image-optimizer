# 画面UIをデザイン画に準拠した構成へ変更

## ステータス

- 承認済み (Accepted)

## 背景・課題

- 画面UIは `docs/design/feature/*.md` のテキスト仕様のみを参照して実装されており、
  `docs/design/feature/images/` のデザイン画（画面構成-画像変換・設定・About）と
  一致しない部分があった。
  - 左サイドナビのメニュー名が `変換` だった（デザイン画は `画像変換`）。
  - 各画面に AppBar があり、タイトルが左上にあった（デザイン画は中央揃えの大きなタイトル）。
  - セクションに枠線カードがなく、タイトルが左揃えだった。
  - フォルダ選択が `テキストボックス+フォルダボタン` だった（デザイン画は `選択ボタン+テキストボックス`）。
  - 情報アイコンがグレーの線画だった（デザイン画は青い四角に白の i）。
  - スライダーの現在値がテキストで表示されていた（デザイン画はサム上部のバブル）。
  - 実行ボタンがデフォルトの `実行` だった（デザイン画は全幅のピンク `変換実行`）。
  - 実行結果がフォームの下に常時表示されていた（デザイン画は実行後に結果ビューへ切替）。
  - 設定画面のバージョン情報が行表示だった（デザイン画は青ヘッダーのテーブル）。

## 決定

- **デザイン画を画面の正とする**。テキスト仕様と矛盾する場合はデザイン画を優先する。
- **左サイドナビ**: メニューを `画像変換`（鉛筆アイコン）`設定`（歯車アイコン）`About`（情報アイコン）に
  変更。アイコンとラベルを横並びで表示し、選択中アイテムは青背景にする。
- **画面タイトル**: AppBar を廃止し、コンテンツ領域の上部に中央揃えの大きなタイトルを表示する。
- **画像変換画面**:
  - 入力・アップスケール・圧縮・処理・出力の各セクションを、枠線カード+中央揃えタイトルで囲む。
  - 各フィールド行を `静的ラベル（固定幅）+ コントロール + 情報アイコン` の横並びにする。
  - フォルダフィールドは `選択`（青ボタン）+ テキストボックス + 情報アイコンの構成にする。
  - スライダーは `ShowValueIndicator.alwaysVisible` で現在値をサム上部のバブルに常時表示する。
  - `変換実行` ボタンを全幅のピンクボタンにする。実行中はローディング表示で無効化する。
  - 初回実行前は入力フォームを表示し、実行後は結果ビュー（上部に `変換実行`、中央に結果、
    画面下部にサマリーを固定）へ切替える。
  - 結果表は青背景のヘッダー行とし、状態は色付きドット+ラベルで表示する。
  - 進捗率バーは青背景で、バー内にパーセンテージを表示する。
- **設定画面**: バージョン情報を青ヘッダー（バイナリ/バージョン）のテーブルで表示する。
  ラベルはデザイン画に従い `upscayl-bin` `upscayl models` とする。
  アクション行は `チェックボックス/プルダウン + 右端に情報アイコン` の構成にする。
- **About画面**: `バージョン` と値を同一行で表示し、`アップデートを確認` ボタンを全幅のピンクにする。
  アラートは背景色+文字色のペアでデザイン画に近づける。
- **色**: `lib/ui/theme/app_colors.dart` を新設し、デザイン画の色（基本の青・アクションのピンク等）を
  定数として一元管理する。アプリのシードカラーも青に変更する。

## 代替案

- 既存の AppBar・左揃えレイアウトを維持する
  - 却下: デザイン画は画面の正であり、それに揃えることが目的のため。
- NavigationRail を使い続ける
  - 却下: デザイン画はアイコン+ラベルの横並びリストであり、縦並びの NavigationRail では再現できないため。

## 結果

- 画面が `docs/design/feature/images/` のデザイン画と一致する構成になった。
- `test/widget_test.dart` の期待値を `変換` から `画像変換` に更新した（テスト自体は維持）。
- 変更箇所: `lib/app/app.dart`、`lib/app/home_shell.dart`、`lib/ui/**`、`test/widget_test.dart`。
