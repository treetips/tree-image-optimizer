# 一括変換の結果表に変換前後のプレビュー比較を追加する

## ステータス

- 承認済み (Accepted)

## 背景・課題

結果表の「前」「後」は Finder を開くリンク（🔗）だけで、最適化の効果（アップスケール・圧縮）を
その場で目視確認できなかった。比較するには Finder で前後の画像を個別に開く必要があった。

## 決定

結果表の各行にプレビュー操作を追加し、選択した行の変換前後をスライダーで比較できる
シートを表示する。

### 実装

- 結果表に「プレビュー」列を追加し、行を選ぶと比較シートを開く。
- 比較ビュー（`BeforeAfterPreviewView`）は変換前・変換後の画像を左右に重ね、
  ドラッグ可能な区切り線で「前 → 後」を連続的に比較する。
- 画像は macOS の `NSImage(contentsOfFile:)` で読み、`Image(nsImage:)` で表示する。
  JXL / AVIF / WebP は macOS 標準の ImageIO がデコードできるため、変換後画像もそのまま表示できる。
- ファイルが存在しない場合は「ファイルが存在しません」を表示する（既存のリンクセルと同様）。

### 対象

- 一括変換の結果表のみ。かんたん変換は1ファイルの即時変換であり、一覧を持たないため対象外。

## 代替案

- **サムネイルを常時表示する**: 数千行の表で全行の画像を読み込むとメモリと描画コストが
  大きい。要求時（シート表示時）だけ読み込む方式を採る。
- **並べて表示するだけ（スライダーなし）**: スライダー比較のほうがアップスケール・圧縮の
  効果が直感的に分かるため、初版からスライダー方式にする。

## 結果

- 結果表から任意の行を選んで、変換前後の見た目をその場で比較できる。
- 実装箇所: `Features/Convert/BeforeAfterPreviewView.swift`（新規）、`ConvertView.swift`、
  `Localizable.xcstrings`。
