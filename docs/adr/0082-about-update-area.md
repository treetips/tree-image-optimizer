# About画面にアプリとライブラリの更新状況を表示する

## ステータス

- 承認済み (Accepted)
- 影響範囲: About画面、アップデート確認、ヘッダーとAboutの共通更新操作

## 背景・課題

About画面にはアプリ情報とバージョン一覧、更新確認ボタンしかなく、アプリとツールの更新有無を同じ画面で確認できなかった。利用者から提供された他プロジェクトのAbout画面では、更新確認ボタンの下にアプリ更新とライブラリ更新を並べ、状態付きの案内とインストールボタンを表示している。

本プロジェクトではツールをライブラリとして表示する。ただし、配布物の取得・検証・配置は既存のツール更新処理をそのまま使う。

## 決定

- About画面はアプリケーションカード、Liquid Glassの更新カード、バージョン情報カードの順に並べる。更新カード内の順序はアプリ更新とライブラリ更新の2列、下部の操作ボタンとする。更新確認とインストールは同時に表示せず、更新が無い場合は確認ボタン、更新がある場合はインストールボタンを表示する。
- 更新状況は確認中・未確認・更新あり・最新・インストール中・再起動待ち・失敗の7種類とする。更新ありは黄色、最新と再起動待ちは緑、失敗は赤、実行中と確認中は進捗表示で区別する。
- アプリ更新は対象バージョンを状態バナーに表示する。見出しの下には状態バナーと同じ説明文を置かず、ライブラリ更新も複数ツールの差分を1つの状態として表示する。
- 更新確認ボタンはアプリとライブラリを同時に確認する。確認結果はヘッダー通知の表示状態とは分けて保持し、通知の自動非表示や手動削除後もAboutに最新の確認結果を残す。
- インストールボタンは既存の共通更新計画を使い、両方に更新がある場合はライブラリを先に更新してからアプリを準備する。再起動待ちは再起動ボタン、失敗時は再実行ボタンへ切り替える。
- 変換中はインストールを無効化する。更新確認と再起動は既存の操作条件に従う。
- 2列は横幅が足りない場合に縦並びへ切り替える。文字サイズの設定にも追従し、状態は色だけでなくアイコンと文言でも伝える。
- インストールボタンは緑色のテーマカラーで表示する。ライト・ダークモードのどちらでも主操作として認識できるよう、不透明度と無効時の表示を揃える。

## 代替案

- 更新状況をヘッダー通知だけに残す
  - 却下: 通知を閉じた後や更新なしカードの自動非表示後に、Aboutで状況を確認できなくなるため。
- アプリとライブラリに別々の確認・インストールボタンを置く
  - 却下: 操作順序を利用者に委ねることになり、既存のライブラリ先行という安全な更新順序を崩すため。
- 進捗・失敗・再起動待ちをAboutに表示せず、静的イメージだけを真似る
  - 却下: 表示と実際の操作が一致せず、更新中に誤った操作を招くため。

## 結果

- About画面だけでアプリとライブラリの更新有無を確認し、必要な更新を開始できる。
- ヘッダー通知を閉じても更新情報は失われず、Aboutから再実行できる。
- 実装箇所: `TreeImageOptimizer/TreeImageOptimizer/Features/About/AboutView.swift`、`TreeImageOptimizer/TreeImageOptimizer/Features/About/AboutUpdatePresentation.swift`、`TreeImageOptimizer/TreeImageOptimizer/Core/UpdateCheckController.swift`、`TreeImageOptimizer/TreeImageOptimizer/Core/ToolsUpdateController.swift`、`TreeImageOptimizer/TreeImageOptimizer/Features/Updates/UpdateToolbarState.swift`、`TreeImageOptimizer/TreeImageOptimizer/App/RootView.swift`、`TreeImageOptimizer/TreeImageOptimizer/Resources/Localizable.xcstrings`。
- テスト: 日英の表示文言、バージョン付き案内の書式、未確認・更新あり・最新・進捗・再起動待ち・失敗の表示と操作を検証する。
