# 更新カードをヘッダー右端へ移動し1行表示にする

## ステータス

- 代替済み (Superseded) — [ADR 0078](./0078-split-releases-and-unified-update-button.md) で更新ボタンを1つに統合

## 背景・課題

ADR 0076 の更新カードは左サイドナビ下部に縦に並べていた。サイドナビの幅は約180px。
更新ありカードのラベルとボタンは2行になっていた。Rex の更新フローと同じ1行表示にできなかった。
アプリ本体とツール更新の両カードを、画面タイトルのあるヘッダー右端へ移す。

## 決定

- アプリ本体とツール更新のカードを、詳細ペインのツールバー右端（`.primaryAction`）へ表示する。
  サイドナビ下部から更新カードを削除する。
- 各カードはラベルとアクションボタンを横に並べた1行のカプセル型 Liquid Glass にする。
- ダウンロード中は確定進捗を小さな横バー、不確定進捗を小さなスピナーで同じ行に表示する。
- 更新なしカードもヘッダー右端へ移動し、クリックで従来どおり非表示化する。
- アプリ本体の青・緑・赤、ツール更新のアクセント・赤という色と、既存の操作・状態遷移は維持する。
- 両カードが同時にある場合は左からアプリ本体、ツール更新の順に横並びで表示する。
- 更新カードの描画を `Features/Updates/UpdateCardsToolbar.swift` に集約し、ルート画面から状態と操作を渡す。

## 代替案

- サイドナビ下部に残す
  - 却下: 幅が足りず、ラベルとボタンが2行になるため。
- ヘッダーに縦積みで表示する
  - 却下: 高さが増え、Rex の1行フローと異なるため。
- 更新カードをメニューやポップオーバーへ隠す
  - 却下: 進捗と再起動ボタンを常時確認できなくなるため。

## 結果

- 更新カードが画面タイトルの右端へ移動し、各カードを1行で表示できる。
- 実装箇所: `App/RootView.swift`、`Features/Updates/UpdateCardsToolbar.swift`、
  `Core/GlassCard.swift`、Xcodeプロジェクト。
- テスト: 既存の更新状態・文言・ステージングのテストを継続して実行する。
