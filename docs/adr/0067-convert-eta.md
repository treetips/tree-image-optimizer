# 一括変換の進捗に残り時間（ETA）を表示する

## ステータス

- 承認済み (Accepted)

## 背景・課題

一括変換は対象が数百〜数千件になり、実行時間が数十分に及ぶことがある。進捗率（%）は
表示されていたが「あとどれくらいかかるか」が分からず、中断・放置の判断がしづらかった。

## 決定

実行中に限り、フッターへ残り時間の概算を表示する。

### 概算の計算

`経過時間 ÷ 完了件数 × 残件数` で求める。

- 完了件数が 0 の間（まだ1件も終わっていない）と、全件完了後は表示しない。
- 経過時間は既存の `elapsedMinutes`（一時停止時間を除いた実稼働時間）を使う。
- 件数は既存の `completedCount`（決着したファイル数）と `rows.count` を使う。
- 表示は「残り: %.1f分」とし、1件あたりの所要時間が安定するまでの誤差は許容する。

### 実装

- `ConvertJobStore` に `estimatedRemainingMinutes` を追加する。計算は純粋関数
  `estimatedRemainingMinutes(elapsed:completed:total:)` に切り出し、単体テスト可能にする。
- `ConvertView` のフッターに、実行中かつ ETA が得られる場合だけ「残り」項目を表示する。

## 代替案

- **残件数だけを表示する**: 件数だけでは所要時間の見積もりにならず、判断材料として弱い。却下。
- **進捗率に残り時間を重ねる**: 進捗率は既に表示されており、重ねると視認性が落ちる。フッターへ独立して表示する。
- **ファイル種別・解像度で重み付けした高精度な見積もり**: 複雑さに対して精度向上が小さく、
  概算で十分。初版は単純平均で近似する。

## 結果

- 実行中に「残り: %.1f分」が表示され、完了までの見通しを立てやすくなる。
- 一時停止中は経過時間が止まるため、ETA も停止して実稼働ベースの見積もりを保つ。
- 実装箇所: `ConvertJobStore.swift`、`ConvertView.swift`、`Localizable.xcstrings`。
