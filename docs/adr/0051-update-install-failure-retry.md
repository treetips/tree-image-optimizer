# 更新インストール失敗時に赤いカードと再実行ボタンを出す

## ステータス

- 承認済み (Accepted)

## 背景・課題

ADR 0050 でインストール中の進捗をサイドナビに表示するようにしたが、ダウンロードや検証に失敗した場合は
カードを「アップデートが有ります」へ戻し、エラーダイアログを出すだけだった。

そのため、失敗したことがカード上では分からず、再試行するにはもう一度カードをクリックして
インストールダイアログを開き直す必要があった。エラーダイアログを閉じた後、
サイドナビだけを見ていると「何も起きていない」ように見えるという課題があった。

## 決定

- `UpdateCard` に `installFailed(UpdateInfo)` を追加する。
- インストール処理が失敗したら、カードを赤背景の `インストールに失敗` に切り替える。
  - 背景色は `Color.red` を既存の更新カードと同じ不透明度でLiquid Glassに重ねる。
  - カード内に `再実行` ボタンを表示する。
- `再実行` は `UpdateCheckController.retryInstall` から `install` を呼び直し、
  ダウンロードからやり直す。`downloadAndPrepare` は開始時に一時ディレクトリを削除するため、
  途中まで受信したファイルは再利用しない（破損したZIPを使い回さない）。
  ダウンロード要求もローカルキャッシュを使わず（`.reloadIgnoringLocalCacheData`）、常に取り直す。
- 失敗の詳細理由は従来どおりエラーダイアログとAbout画面のメッセージに表示する。
  カードは狭く長いエラー文を載せるとレイアウトが崩れるため、状態と再試行だけを担う。
- 再実行中はカードが進捗表示へ戻り、二重実行は `isInstalling` で防ぐ。

## 代替案

- 失敗しても「アップデートが有ります」カードへ戻す（ADR 0050 の初期実装）
  - 却下: 失敗したことが分からず、再試行にもダイアログを開き直す手間がかかる。
- 赤背景にするだけで再実行ボタンは置かない
  - 却下: 再試行の導線がダイアログの奥に残り、カード内で完結できない。
- 失敗時に自動でリトライする
  - 却下: ネットワーク断やSHA-256不一致が続く場合に無限に再試行し、
    ユーザーの意図しない通信を続ける。再実行は明示操作にする。
- 失敗理由をカード内に全文表示する
  - 却下: サイドナビの幅では長いエラー文が折り返されてカードが肥大化する。
    詳細は既存のダイアログとAbout画面に残す。

## 結果

- 失敗するとサイドナビに赤い `インストールに失敗` カードが出て、その場で `再実行` できる。
- 再実行はダウンロードからやり直す。
- 実装箇所: `Core/UpdateCheckController.swift`（`installFailed`・`retryInstall`）、
  `App/RootView.swift`（失敗カード）、`Resources/Localizable.xcstrings`（`nav.installFailed`・`nav.retry`）。
- テスト: 失敗カードの文言（日英）のローカライズ。
