# 通知

## 変換画面

### OSの通知

- 変換終了時に、OSの通知を表示したい。
- `設定画面` で設定したい。

### サウンドの再生

- 変換が成功したら、成功サウンドを再生したい。
- 変換が失敗したら、失敗サウンドを再生したい。

#### 成功サウンドと失敗サウンド

- 全ファイル成功したら、成功サウンドを再生する。
- 1ファイルでも失敗したら、失敗サウンドを再生する。
- `成功サウンド` と `失敗サウンド` は `設定画面` で選択する。
- `成功音サウンド声` `失敗サウンド` それぞれにサンプルとしてサウンドをプロジェクトに同梱する。

#### ユーザーサウンド

- ユーザーが自分で用意した音声ファイルも使えるようにしたい。
- 以下にファイルが配置されている場合、設定画面のプルダウンに表示して選択できるようにしたい。
    - 成功サウンド: `.config/tree-image-optimizer/sounds/success`
    - 失敗サウンド: `.config/tree-image-optimizer/sounds/error`

## 通知の注意点

OSの通知は、OS側の権限設定が必要。
