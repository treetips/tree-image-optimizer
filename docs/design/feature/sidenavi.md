# サイドナビ

## メニュー

アイコン + ラベル という構成でメニューを表示します。

- 一括画像変換
- かんたん画像変換
- 設定
- About

## アップデート通知

- 更新チェックの結果を、サイドナビの最下部に更新カードとして表示します。
  - 表示のきっかけは、アプリケーション起動時の自動チェックと、`About画面` の `アップデートを確認` ボタン・メニューバーの `更新を確認` による手動チェックです。手動チェックで失敗した場合は表示を変更しません。

### アップデートが有る場合

- `アップデートが有ります` ボタンを表示します。
- クリックすると、アップデートのインストールダイアログを表示します。
- OSのテーマカラーを背景色とします。
- ホバーするとカーソルをポインターにし、クリックできることが分かるようにします。

### インストール中の場合

- インストール開始後は `インストール中` を表示します（ダイアログは閉じます）。
- ダウンロード中は `ダウンロード 42%` のような進捗率とプログレスバーを表示します。
- 検証・展開・コピー中は段階に応じた文言と不確定バーを表示します。
- カードはクリックできません。完了するとアプリは新しいバージョンで再起動して終了します。
- 失敗時は背景を赤色にした `インストールに失敗` カードに切り替え、カード内の `再実行` で
  ダウンロードからやり直せます。

### アップデートが無い場合

- `アップデートは有りません` を表示します。
- クリックすると更新カードを非表示にします。10秒後には自動的にも非表示になります。
- 背景色は透明で目立たない色にします。
