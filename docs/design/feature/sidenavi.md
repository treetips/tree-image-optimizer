# サイドナビ

## メニュー

アイコン + ラベル という構成でメニューを表示します。

- 一括画像変換
- かんたん画像変換
- 設定
- About

## アップデート通知

- 更新チェックの結果は、画面タイトルのあるヘッダー右端に更新カードとして表示します。
  - 表示のきっかけは、アプリケーション起動時の自動チェックと、`About画面` の `アップデートを確認` ボタン・メニューバーの `更新を確認` による手動チェックです。手動チェックで失敗した場合は表示を変更しません。
- アプリ本体とツールの更新は独立したカードで、左からアプリ本体・ツールの順に横並びで表示します。
  片方だけ更新がある場合はそのカードだけを表示します。
- 各カードはラベルと操作を1行にまとめたカプセル型 Liquid Glass で表示します。

### アップデートが有る場合

- 青背景の `アップデートがあります` カードを表示します。
- カード内の `ダウンロード` ボタンをクリックすると、そのままダウンロードを開始します。
- ボタンにホバーするとカーソルをポインターにし、クリックできることが分かるようにします。

### インストール中の場合

- 青背景のカードへ切り替え、ダウンロード中は `ダウンロード中... 42%` と小さな確定バーを
  同じ行に表示します。総バイト数が不明な場合は `ダウンロード中...` と小さな不確定スピナーにします。
- 検証・展開・ステージング中は段階に応じた文言と小さな不確定スピナーを表示します。
- カードはクリックできません。完了すると緑背景の `アップデート完了` カードへ切り替わります。
- 失敗時は背景を赤色にした `インストールに失敗` カードに切り替え、カード内の `再実行` で
  ダウンロードからやり直せます。

### 再起動待ちの場合

- 緑背景のカードに `アプリ再起動する` ボタンを表示します。
- ボタンをクリックすると、新しいアプリを起動して現在のアプリを終了します。自動再起動はしません。

### アップデートが無い場合

- `アップデートは有りません` を表示します。
- クリックすると更新カードを非表示にします。10秒後には自動的にも非表示になります。
- 背景色は透明で目立たない色にします。

### ツール更新が有る場合

- アクセント色の `ツール更新が有ります` カードを表示します。更新が無い場合はカード自体を表示しません。
- カード内の `インストール` ボタンをクリックすると確認ダイアログを表示し、更新対象のツール名を列挙します。
- 更新中は `インストール中` カードに切り替わり、ツール名と進捗を同じ行に表示します。
- 完了してもアプリは再起動しません。失敗時は赤いカードの `再実行` からやり直せます。
- ツール更新中は変換画面の実行を抑止します（`tools/<name>` を置換するため）。
