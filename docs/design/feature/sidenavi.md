# サイドナビ

## メニュー

アイコン + ラベル という構成でメニューを表示します。

- 一括画像変換
- かんたん画像変換
- 設定
- About

## アップデート通知

- アップデートが有る場合、 サイドナビの最下部に `アップデートが有ります` ボタンを表示します。
- アップデートが無い場合は表示しません。
- `アップデートが有ります` ボタンをクリックすると、 `About画面` の `アップデートを確認` ボタンと同じ挙動をします。
- アップデートが有る場合
  - OSのテーマカラーを背景色とします。
  - ホバーするとカーソルをポインターにし、クリックできることが分かるようにします。
- アップデートが無い場合、背景色は無しです。
