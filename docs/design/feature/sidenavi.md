# サイドナビ

## メニュー

アイコン + ラベル という構成でメニューを表示します。

- 一括画像変換
- かんたん画像変換
- 設定
- About

## アップデート通知

- 更新チェックの結果は、画面タイトルのあるヘッダー右端に更新カードとして表示します。
  - アプリは起動時と、`About画面` の `アップデートを確認` ボタン・メニューバーの `更新を確認` で確認します。ツールは初回準備が完了した後の起動時に確認します。手動チェックで失敗した場合は表示を変更しません。
- アプリ本体とツールの更新は1個の統合更新ボタンで表示します。
- 更新ボタンはラベルと操作を1行にまとめたカプセル型 Liquid Glass です。

### アップデートが有る場合

- 青背景の統合更新ボタンを表示します。文言は `アプリの更新があります`、`ツールの更新があります`、`アプリとツールの更新があります` の3種類です。
- ボタンをクリックすると、利用可能な更新をそのまま開始します。両方ある場合はツールを先に更新します。
- ボタンにホバーするとカーソルをポインターにし、クリックできることが分かるようにします。

### インストール中の場合

- 青背景のカードへ切り替え、ダウンロード中は `ダウンロード中... 42%` と小さな確定バーを
  同じ行に表示します。総バイト数が不明な場合は `ダウンロード中...` と小さな不確定スピナーにします。
- 検証・展開・ステージング中は段階に応じた文言と小さな不確定スピナーを表示します。
- カードはクリックできません。完了すると緑背景の `アップデート完了` カードへ切り替わります。
- 失敗時は背景を赤色にした `インストールに失敗` カードに切り替え、カード内の `再実行` で
  ダウンロードからやり直せます。

### 再起動待ちの場合

- 緑背景のカードに `アプリ再起動する` ボタンを表示します。
- ボタンをクリックすると、新しいアプリを起動して現在のアプリを終了します。自動再起動はしません。

### アップデートが無い場合

- `アップデートは有りません` を表示します。
- クリックすると更新カードを非表示にします。10秒後には自動的にも非表示になります。
- 背景色は透明で目立たない色にします。

### ツール更新が有る場合

- ツールだけに更新がある場合は `ツールの更新があります` を表示します。
- アプリと両方ある場合は `アプリとツールの更新があります` を表示し、ツールの成功後にアプリ更新を開始します。
- 更新中はツール名と進捗を同じ行に表示します。
- ツール更新中は変換を開始しない。更新操作は変換の完了後だけ有効にします。
- 完了してもアプリは再起動しません。失敗時は赤いカードの `再実行` から未完了の更新をやり直せます。
