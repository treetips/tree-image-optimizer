# 共通パーツ

## alert

- 標準のアラートを使い、背景色はOSの外観に従います。
- 更新結果はアイコンと文言で区別し、独自の背景色は付けません。
  - 更新なし: `アップデートは有りません` と `アプリは最新バージョンです。`
  - 更新あり: 確認ダイアログは出さず、ヘッダー右端の統合更新ボタンで通知する
  - 確認失敗: `アップデートの確認に失敗しました` と失敗理由
- 通常は自動で非表示になりません。

## 結果メッセージ

- 一括変換の結果は、実行結果の上にテキストで表示します。
- 成功・失敗・キャンセルは文言で区別します。
  - 全件成功: `変換完了：成功N件`
  - 失敗あり: `変換完了：成功N件・失敗M件`
  - キャンセル: `キャンセルしました：成功N件・未完了M件`
- かんたん変換の結果は、ドロップエリア内に表示します。

## チェックボックス

- 標準のチェックボックスを使います。
- ラベルをクリックすると、チェック状態を切り替えることができます。

## ラジオボタン

- ボタンでラジオ風の見た目を実装します。選択中は塗りつぶしの円とテーマカラーの枠で示します。
- ラベルをクリックすると、選択状態を切り替えることができます。
