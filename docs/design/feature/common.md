# 共通パーツ

## alert

- アップデートが無い場合は `緑色背景色` 。
- アップデートが有る場合は `黄色背景色` 。
- アップデートに失敗した場合は `赤色背景色` 。
- 通常は自動で非表示になりません。

## スナックバー

- 処理に成功した場合は `緑背景色` 。
- 処理に失敗した場合は `赤背景色` 。
- `CLOSEボタン` をクリックするとスナックバーを非表示にします。
- `5秒` 経過すると非表示になります。

## チェックボックス

- ラベルボタンをクリックすると、チェック状態を切り替えることができます。

## ラジオボタン

- ラベルボタンをクリックすると、チェック状態を切り替えることができます。
